# Sales Performance Dashboard

## Project Overview
An interactive sales dashboard developed using Microsoft Excel and Power BI to analyze sales performance across products, categories, regions, and salespersons.

## Tools Used
- Microsoft Excel
- Microsoft Power BI

## Key Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Profit Margin KPI
- Product-wise Sales analysis
- Region-wise Sales analysis
- Category-wise Sales analysis
- Salesperson-wise Sales analysis
- Interactive Region and Category filters

## Project Files
- Sales_Performance_Dashboard.pbix – Power BI dashboard
- Sales_Performance_Dashboard.xlsx – Excel source data
- Sales_Performance_Dashboard_Screenshot.png – Dashboard preview

## Objective
To analyze sales performance and present business insights through an interactive dashboard.
